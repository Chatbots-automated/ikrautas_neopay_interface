PROBLEM:
"I see very little actual rows. Just for this month but this system 
has been running for about a year now."

SOLUTION:
Import all historical data from Monday.com with ONE CLICK!

╔════════════════════════════════════════════════════════════════╗
║  STEP-BY-STEP INSTRUCTIONS                                     ║
╚════════════════════════════════════════════════════════════════╝

1. Make sure your dev server is running:
   
   npm run dev

2. Open your browser and go to:
   
   http://localhost:3000/payments

3. Look for the button:
   
   🔄 Sinchronizuoti iš Monday

4. Click it and confirm the action

5. Wait 4-5 minutes for ~1100 items to sync

6. You'll see a popup with results:
   
   Sinchronizacija baigta!
   
   Iš viso: 1100 Monday įrašų
   Avanso mokėjimų: 450
   Galutinių mokėjimų: 380
   Klaidų: 2

7. ALL your historical payments are now in the dashboard! 🎉

╔════════════════════════════════════════════════════════════════╗
║  TROUBLESHOOTING                                               ║
╚════════════════════════════════════════════════════════════════╝

Q: Sync taking too long?
A: Normal for 1000+ items. Can take 5+ minutes. Be patient!

Q: Some payments didn't sync?
A: Check the "Klaidų" (errors) count. Empty URLs are skipped.

Q: Still seeing few rows?
A: Make sure you ran the database migration first:
   supabase/migrations/001_payment_control_tables_safe.sql

Q: Want to run sync again?
A: Totally safe! It won't create duplicates. Click the button again.
